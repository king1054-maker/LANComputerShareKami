# v0.1.0-alpha.1 · 首个仓库测试版

把局域网内的另一台电脑显示为文件窗口，直接拖放复制、浏览、删除和改名。每个目录由所属电脑管理，没有后台双向镜像或跨机器时间戳覆盖规则。

提供自包含 Windows x64 程序、源码包、SHA-256 校验清单和机器可读的 release-manifest。

发布门槛：Linux 核心测试、Windows 核心测试、Windows 程序构建、Windows COM 拖放自检全部通过。实际运行记录在 manifest 的 workflow_run_url。

**仍未完成 Windows 11 两台实体电脑的人工联调。** Windows CI 使用 Windows Server runner；它不等同于 Windows 11 双机验收。请先使用测试文件。

限制：文件级重试，没有字节级续传；远程拖出/打开会完整缓存到本机；没有边传边播或公网穿透；尚未代码签名。

使用：两台电脑各自解压 Windows 包，普通用户运行 LanBridge.exe，允许可信专用网络通信，核对配对码后开始拖放。
